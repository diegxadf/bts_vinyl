      Cómo conseguir la clave (5 minutos, gratis)
      1. Entra en console.cloud.google.com con tu cuenta de Google y crea un proyecto (p. ej. "BTS Vinyl").
      2. En APIs y servicios → Biblioteca, busca YouTube Data API v3 y pulsa Habilitar.
      3. En APIs y servicios → Credenciales, pulsa Crear credenciales → Clave de API y cópiala.
      4. Recomendado: en la clave, Restricciones de API → YouTube Data API v3.
      5. Pégala arriba y toca Probar. Se guarda sola.

      Cada canción se busca una sola vez y queda guardada. El cupo gratuito da para unas 100 canciones nuevas al día.
